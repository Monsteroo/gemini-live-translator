Як користуватися

Двосторонній перекладач для Zoom: ви говорите українською → співрозмовник чує англійською; він говорить англійською → ви читаєте українською.

1. Один раз: налаштувати звук (macOS)

  • Увімкнути навушники (обов'язково — інакше мікрофон ловить голос зі спікерів і виникає відлуння).
  • Audio MIDI Setup → + → Create Multi-Output Device → позначити BlackHole 16ch + ваші навушники.

2. У Zoom (Settings → Audio)

  • Динамік → створений Multi-Output Device (чуєте оригінал + скрипт перекладає).
  • Мікрофон → BlackHole 2ch (сюди йде ваш переклад).
  • Original Sound: ON, шумоприглушення Off.

3. У цьому вікні

  1. «Співрозмовнику» → потрібна мова (для англійця — English).
  2. Поле Мік → ваш реальний мікрофон (напр. MacBook).
  3. Натиснути Старт → внизу мають з'явитися пристрої без «None».
  4. Говорите українською → праворуч англійський текст, співрозмовник чує голос.
  5. Він говорить → ліворуч український переклад (ви читаєте + чуєте оригінал у навушниках).

4. Перевірка без співрозмовника

  • Кнопка 🧪 Подати англійською імітує співрозмовника — у лівій панелі з'явиться український переклад.
  • «чути свій переклад» — почути власний англійський голос у навушниках (для соло-тесту).

5. Тест затримки

  • Старт (движок Gemini) → ⏱ Тест затримки. ~40 с: дві українські фрази «ви → співрозмовник» і одна англійська «співрозмовник → ви».
  • Не говоріть під час тесту. Запускайте до дзвінка — співрозмовник у Zoom почує тестові фрази.
  • Таблиця показує, коли з'явився текст, прийшов звук і пішов у Zoom. Історія — у latency_log.jsonl.
⏱ Затримка 3–4 секунди — це норма для голосового перекладу (модель чекає кінець фрази, інакше ламається порядок слів). Швидше технологічно неможливо.
